# Archived paper plotting implementation

These source files are preserved byte-for-byte from repository commit
`230061dc49257f43ba1e064bbaa520cd60a590ec` (before the experimental calculator).
They are not imported by the new `rgsp_toolkit` package or included in its wheel.
The original `build/` and `.egg-info/` duplicates remain in Git history.

Use the root README for the supported calculator. The archived code may require
its original dependencies and is retained for provenance, not maintained as part
of the new experimental API.
